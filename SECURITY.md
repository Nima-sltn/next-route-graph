# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.2.x   | :white_check_mark: |
| 1.1.x   | :white_check_mark: |
| 1.0.x   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in `next-route-graph`, please report it responsibly:

1. **Do not open a public GitHub issue.**
2. Send an email to the repository maintainer or open a private security advisory through GitHub.
3. Include detailed steps to reproduce the issue along with a minimal reproduction project if possible.

You will receive an acknowledgment within 48 hours, followed by updates on the timeline for a patch.
